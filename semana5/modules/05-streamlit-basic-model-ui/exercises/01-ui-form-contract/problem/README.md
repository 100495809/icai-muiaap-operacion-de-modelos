# Práctica 01 — Contrato del formulario Streamlit

**Modalidad:** parejas · **Duración:** 40–50 minutos

## Objetivo

Convertir el contrato de entrada de S4 en un diseño de formulario que otra
pareja pueda implementar sin inventar nombres, rangos ni etiquetas.

- [Notebook del alumnado](01-ui-form-alumno.ipynb).

| --- | --- | --- | --- | ---: | ---: | ---: |
| `fixed_acidity` | TODO | TODO | TODO | TODO | TODO | TODO |

Además:

1. decidid qué botón envía la petición;
2. indicad qué no debe ocurrir al cambiar un widget;
3. diseñad el contenido mínimo de un resultado;
4. describid un error que S5 puede mostrar y dos limitaciones que quedan para
   S6.

## Comprobación

Otra pareja debe poder implementar el formulario leyendo solo vuestra tabla.
No incluyáis código de inferencia ni una segunda definición de las features.
