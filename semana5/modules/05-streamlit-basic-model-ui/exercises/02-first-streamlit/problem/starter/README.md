# Starter — Primera interfaz Streamlit

Este es el único proyecto de código que recibe el alumnado. El gateway,
contrato y presentación básica vienen preparados; los `TODO` están en
`app.py`.

Implementadlos siguiendo el orden de la [práctica](../../README.md). La
solución de S5 se utiliza después como snapshot de partida para S6.

El `DemoGateway` evita depender de un binario durante el taller. El bundle real
se activa con `MODEL_UI_BUNDLE` y se carga mediante el adaptador de S4.
